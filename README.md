# postgresql-netflix-database
A PostgreSQL project analyzing Netflix titles using SQL queries.

## Tools Used
- PostgreSQL
- pgAdmin 4

## What's Inside
- 14 business questions on the netflix_titles dataset
- Aggregations (COUNT, MIN, MAX, AVG, GROUP BY, HAVING)
- CASE statements to categorize content and ratings
- String functions (LEFT, RIGHT, LENGTH, TRIM, STRING_TO_ARRAY, UNNEST)
- Date functions (EXTRACT)
